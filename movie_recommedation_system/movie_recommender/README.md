# movie_recommender/

This folder contains the **Jupyter notebooks** used for experimentation and for generating the artifacts/data that the Streamlit app relies on.

Recommended workflow: run notebooks in order to regenerate artifacts from scratch.

## Notebooks
- `01_data_preparation.ipynb`
  - Loads MovieLens data and enriches it with TMDB metadata (overview, poster path, genres, etc.).
  - Writes outputs to `data/processed/` and caches to `cache/`.
- `02_Content_Based_Engine.ipynb`
  - Builds the content-based representation (Sentence-Transformer embeddings).
  - Saves embeddings to `artifacts/content/`.
- `03_Collaborative_FIiltering_Engine.ipynb`
  - Trains the collaborative filtering model (Surprise SVD) on MovieLens ratings.
  - Saves `artifacts/svd_model.pkl` and `artifacts/svd_metadata.pkl`.
- `04_Hybird.ipynb`
  - Experiments with blending content and collaborative scores (hybrid scoring).
  - Writes optional configuration artifacts (example: `artifacts/hybrid_config.pkl`).
- `05_Adding_Explanation.ipynb`
  - Adds/experiments with human-readable explanations for why a movie was recommended.
  - Writes optional configuration artifacts (example: `artifacts/explanation_config.pkl`).

## Notes
