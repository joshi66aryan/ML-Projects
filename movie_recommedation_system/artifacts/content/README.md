# artifacts/content/

This folder contains **content-based recommendation artifacts**.

These files are generated by the notebook `movie_recommender/02_Content_Based_Engine.ipynb` and then loaded by the Streamlit app.

## Files
- `movie_embeddings.npy`
  - A NumPy array of dense vectors (shape: `num_movies × embedding_dim`).
  - Used in `app.py` to compute cosine similarity for “More Like This Movie”.
- `embedding_metadata.pkl`
  - Metadata about how embeddings were generated (example: model name, embedding dimension, run details).
  - Not required by the app, but helpful for traceability.
- `enriched_movies_with_embeddings.pkl`
  - Legacy/experimental export.
  - The current app does **not** need this file because it already uses:
    - `data/processed/enriched_movies.csv` (movie metadata)
    - `movie_embeddings.npy` (vectors)
